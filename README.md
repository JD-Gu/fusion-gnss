# Fusion GNSS

This repository demonstrates GNSS/IMU data fusion with integration of RTKLIB. All sensor data is read from files and fused navigation results are saved back to disk.

## Usage

1. Save your GNSS observations and IMU measurements as files.
2. Run the fusion script configured for your dataset.
3. The processed position and attitude estimates will be written to output files.
